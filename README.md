## Текущий статус проекта

Проект находится в процессе разработки.

На текущем этапе реализованы и отдельно протестированы основные компоненты:

* генерация текста с помощью OpenAI;
* генерация изображений с помощью `gpt-image-1`;
* сохранение сгенерированных изображений в формате PNG;
* подключение к API ВКонтакте;
* загрузка изображений в VK;
* публикация постов с изображениями;
* получение статистики сообщества и опубликованных постов.

### Что работает

Генератор изображений успешно создаёт изображения с помощью OpenAI и сохраняет их в проекте.

Модуль `VKPublisher` успешно подключается к API ВКонтакте, загружает изображения и публикует посты с прикреплёнными изображениями.

Таким образом, основные компоненты проекта были разработаны и проверены отдельно.

### Что пока не завершено

На текущем этапе не удалось стабильно объединить генерацию изображения через OpenAI и последующую автоматическую публикацию этого изображения во ВКонтакте в единую цепочку:

**OpenAI → генерация изображения → VK → загрузка изображения → публикация поста**

Причина связана с сетевым соединением при использовании VPN.

При работе через VPN соединение Python с upload-серверами ВКонтакте (`pu.vk.com`) становится нестабильным. В процессе передачи изображения возникают ошибки:

* `ConnectionResetError`;
* `ConnectionError`;
* `502 Bad Gateway`;
* ошибки разрешения и установления соединения с сервером.

При этом отдельно подтверждено, что:

* генерация изображения через OpenAI работает;
* VK API успешно отвечает на запросы;
* VK API успешно возвращает `upload_url`;
* `VKPublisher` способен загрузить изображение и опубликовать пост при стабильном соединении с VK;
* проблема возникает именно при передаче файла на upload-сервер VK (`pu.vk.com`) через используемое VPN-соединение.

Поэтому на данный момент интеграция OpenAI и VK не доведена до полностью стабильной автоматической цепочки.

### План дальнейшей разработки

После решения проблемы с сетевым соединением планируется объединить разработанные компоненты в единый процесс:

1. Сгенерировать текст поста.
2. Сгенерировать изображение через OpenAI.
3. Передать изображение на сервер VK.
4. Создать публикацию с текстом и изображением.
5. Добавить автоматическую публикацию постов по расписанию.
6. Использовать статистику VK для анализа опубликованного контента.

# BookSMM
Проект для автоматизации создания и публикации контента книжного сообщества во 
ВКонтакте с использованием инструментов OpenAI.

Объединяет генерацию идей и текстов публикаций, создание изображений, автоматическую публикацию контента, а также 
получение статистики сообщества и опубликованных записей.

## Возможности проекта

### Генерация контента

* Автоматическая генерация тем для публикаций с помощью OpenAI.
* Создание текстов постов на основе выбранной темы.
* Генерация описаний изображений с учётом содержания публикации.
* Создание изображений с помощью модели `gpt-image-2`.
* Сохранение сгенерированных изображений в формате PNG.

### Публикация во ВКонтакте

* Подключение к VK API.
* Загрузка изображений в сообщество.
* Автоматическая публикация постов с текстом и изображениями на стене сообщества.

### Получение статистики

Реализован отдельный модуль `VKStats` для работы с данными сообщества через VK API.

Доступны три метода:

* `get_stats(start_date, end_date)` — получение статистики сообщества за указанный период.
* `get_followers()` — получение текущего количества подписчиков.
* `get_posts(count=10)` — получение последних публикаций со стены сообщества.

Методы обрабатывают ошибки сетевых запросов, HTTP-ответов и ответов VK API.

## Как работает проект

Основной сценарий автоматизации объединяет несколько компонентов:

**TopicGenerator → PostGenerator → ImageGenerator → VKPublisher**

Последовательность работы:

1. Генерируется тема будущей публикации.
2. На основе темы создаётся текст поста.
3. Формируется описание изображения.
4. Генерируется изображение для публикации.
5. Изображение загружается во ВКонтакте.
6. Готовая публикация размещается на стене сообщества.

Получение статистики выполняется отдельно с помощью VKStats.

Основная цепочка генерации и публикации, а также методы 
получения статистики проверены на реальных запросах к API.

## Используемые технологии

* Python — основной язык разработки.
* OpenAI API — генерация тем и текстов.
* OpenAI Image Generation API — создание изображений (gpt-image-2).
* VK API — публикация контента и получение статистики сообщества.
* Requests — выполнение HTTP-запросов.

## Настройка проекта

1. Клонируйте репозиторий:

```text
git clone https://github.com/VikkMoor/BookSMM.git
```
2. Установите необходимые зависимости:

```text
pip install openai requests python-dotenv
```

3. Создайте файл `.env` в корневой папке проекта и укажите параметры
доступа:

```text
OPENAI_API_KEY=your_openai_api_key
VK_API_KEY=your_vk_api_key
VK_GROUP_ID=your_vk_group_id
```

4. Убедитесь, что файл `.env` добавлен в `.gitignore` и конфиденциальные 
данные не публикуются в репозитории.

## Запуск

Основной сценарий работы находится в файле `main.py`.

Важно: запуск `main.py` выполняет полный цикл: обращается к OpenAI API, генерирует текст и изображение,
загружает их во ВКонтакте и публикует новую запись на стене сообщества. Генерация изображений и текстов 
расходует средства API OpenAI.

Методы получения статистики находятся в `social_stats/vk_stats.py` и могут вызываться независимо от 
основного сценария публикации.

## Текущий статус проекта

Проект находится в процессе разработки.

На текущем этапе реализованы и протестированы основные компоненты:

* генерация текста с помощью OpenAI;
* генерация изображений с помощью `gpt-image-1`;
* сохранение сгенерированных изображений в формате PNG;
* подключение к API ВКонтакте;
* загрузка изображений в VK;
* публикация постов с изображениями;
* получение статистики сообщества и опубликованных постов.

### Что работает

Основная цепочка автоматической публикации успешно реализована и протестирована:

**OpenAI → генерация изображения → сохранение PNG → VK → загрузка изображения → публикация поста.**

Генератор изображений создаёт изображение с помощью OpenAI и сохраняет его в проекте.

Модуль `VKPublisher` подключается к VK API, загружает изображение и создаёт публикацию с прикреплённым изображением.

Таким образом, основные компоненты проекта работают как отдельные модули и могут быть объединены в единый процесс публикации.

### Особенности разработки

В процессе разработки возникали проблемы с сетевым подключением к API OpenAI и upload-серверам VK при использовании VPN.

После настройки сетевого соединения полная цепочка:

**генерация изображения → загрузка изображения в VK → публикация поста**

была успешно выполнена из Python-кода.

### План дальнейшей разработки

Следующим этапом планируется развитие автоматизации:

1. Генерировать текст поста.
2. Генерировать изображение через OpenAI.
3. Передавать изображение в VK.
4. Создавать публикацию с текстом и изображением.
5. Добавить автоматическую публикацию по расписанию.
6. Использовать статистику VK для анализа опубликованного контента.
7. Развивать автоматизацию работы с контентом с использованием AI.

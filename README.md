# BookSMM
Проект для автоматизации создания и публикации контента книжного сообщества во 
ВКонтакте с использованием инструментов OpenAI.

Объединяет генерацию тем, написание текстов, создание изображений и автоматическую 
публикацию готовых постов.

## Реализованные возможности

* Автоматическая генерация тем для публикаций с помощью OpenAI.
* Генерация текстов постов на основе выбранной темы.
* Создание описаний изображений, соответствующих содержанию публикации.
* Генерация изображений с помощью модели gpt-image-2.
* Сохранение изображений в формате PNG.
* Подключение к API ВКонтакте.
* Загрузка изображений на сервер VK.
* Автоматическая публикация постов с текстом и изображениями в сообществе.

## Как работает проект

На текущем этапе реализована единая автоматизированная цепочка:

**TopicGenerator → PostGenerator → ImageGenerator → VKPublisher**

Последовательность работы:

1. Генерируется тема будущей публикации.
2. На основе темы создаётся текст поста.
3. Создаётся описание изображения для визуального сопровождения публикации.
4. Генерируется изображение.
5. Изображение загружается во ВКонтакте.
6. Публикуется готовый пост с текстом и изображением.

Полная цепочка успешно протестирована: посты автоматически генерируются и публикуются
в сообществе VK.

## Запуск проекта

Основной сценарий запуска находится в файле `test.py`.

Перед запуском необходимо настроить API-ключ OpenAI и параметры доступа к сообществу VK в конфигурации проекта.

**Важно:** запуск `test.py` выполняет полный цикл генерации и публикации. При успешном выполнении в сообществе VK появляется новая публикация. Запуск также расходует средства API OpenAI.

Секретные ключи и другие конфиденциальные данные хранятся в `.env` и не должны попадать в публичный репозиторий.
